# pipeblob

Pipe HTML/Markdown blob fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/pipeblob/

## Install / run

```bash
git clone https://github.com/theworker02/pipeblob.git
cd pipeblob
node src/cli.js
node --test
```
